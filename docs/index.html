About the Lab

Rigorous research,
automated end-to-end

The lab runs research questions through a five-phase pipeline of specialist Claude Code agents. Each specialist has a single remit: the research strategist verifies novelty, the literature specialist retrieves and cites papers, the data scientist runs analysis and produces figures, the academic writer drafts the manuscript, and the peer reviewer audits every claim.

Nothing advances without passing a scored quality gate. Every factual claim carries provenance — the tool that retrieved it, the query used, and the retrieval date. No fabricated citations; no rubber-stamping.

🔬
Empirical novelty verification

Three distinct queries run across live scholarly databases before any angle is declared novel. Closest prior works are cited by DOI.

📋
Scored quality gates

Every phase deliverable is scored 1–5 across five criteria. A score of ≤2 on any criterion forces revision before the pipeline advances.

✍️
Human-indistinguishable prose

The ghost-writer layer applies sentence entropy, domain-specific lexical grounding, and irregular rhythm to produce writing that reads as naturally human.

🔗
Provenance on every claim

Tool name, query string, and retrieval date travel with each fact from search through final manuscript.

Research Pipeline

Five phases, one gated pipeline

Phases run in order. Each must pass a PI scorecard before the next begins. The engine resumes from the last passed phase — a failed run picks up where it stopped.

Quality Protocol

Nothing ships without a scorecard

Every phase deliverable is scored before the pipeline advances. The PI reads the artifact — not the agent's summary.

APPROVE
All criteria ≥ 3, no blockers

Artifact promoted; pipeline advances to next phase.

REVISE
Any criterion ≤ 2 — max 2 rounds

Scorecard returned to the same specialist. After two rounds, escalates to user.

REJECT
Wrong approach — not fixable

Re-plan from scratch; root cause logged in run_log.md.

Quick Start

Running your first project

Setup & Run 
# Clone the lab
git clone https://github.com/charchitd/MyResearch_Lab.git
cd MyResearch_Lab

# Bootstrap folders + sync agents
./run_lab.sh setup

# Register MCP servers
./run_lab.sh mcp

# Validate everything
./run_lab.sh doctor

# Run Phase 0 intake (PI will ask for resources)
./run_lab.sh phase 0 my-project "your research question"

# Or run the full pipeline automatically
./run_lab.sh all my-project "your research question"
